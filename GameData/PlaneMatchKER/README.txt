PlaneMatchKER 1.0.2

Required:
- KSP 1.12.5
- Kerbal Engineer Redux 1.1.9.5

Select a valid same-body target vessel to reveal the PLNE tab in Flight
Engineer.

PlaneMatchKER is display-only. It never commands flight controls or SAS.

The atmospheric bank cue is hidden in vacuum; orbital plane telemetry remains
available.
