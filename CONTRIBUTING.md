# Contributing

Keep the suite narrowly focused on display-only rendezvous information.

Changes should:

- preserve KSP 1.12.5 and KER 1.1.9.5 compatibility;
- preserve the separate `WIND` and `PLNE` operational roles;
- avoid flight-control, SAS, staging, throttle, and time-warp code;
- retain clear distinctions between position proximity and velocity matching;
- pass the full stable smoke test;
- use GPL-3.0-or-later source headers.
